# Sponsor artwork

Upload the supplied Minty's Bedtime Stories picture to this folder and commit to `main`.
PNG, JPG, JPEG and WebP are supported. No specific filename is required. Keep only one
image in this folder; if several are present, the app uses the first alphabetically.

The picture appears in full in the top-right sponsor panel on both competition pages.
It is embedded from the repository, with no external image host or cropping required.
